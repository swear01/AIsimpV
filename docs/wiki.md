# GitHub Wiki 維護

[Wiki 首頁](https://github.com/swear01/AIsimpV/wiki)是給人閱讀的導覽與結果摘要；repo 的 `README.md`、`docs/`、實驗文件及資料檔是內容來源。

修改這些原始文件時，檢查 Wiki 的[首頁](https://github.com/swear01/AIsimpV/wiki)、[結果與證據](https://github.com/swear01/AIsimpV/wiki/Results-and-Evidence)和[驗證方法與重跑](https://github.com/swear01/AIsimpV/wiki/Method-and-Reproduction)。若結論、數據解讀、實驗狀態、重跑步驟或導覽連結受影響，同一任務同步修改對應 Wiki 頁面；純文字修正且不影響摘要時，完成報告中註明已檢查、無需更新。

Wiki 是獨立的 Git repository：`https://github.com/swear01/AIsimpV.wiki.git`。從遠端最新版本編輯，推送後打開公開頁面檢查內容與連結。維持原報告的 task 範圍、證據等級與失敗紀錄，不把 frontend PASS、property SAFE、證書 ACCEPTED 或效能提升混為同一結果。若無法推送，明確回報 Wiki 尚未同步與原因。
