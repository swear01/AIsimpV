1. Added one addrdecode instance per master to produce rrequest from S_AXI_ARVALID and S_AXI_ARADDR, using OPT_REGISTERED=0 and i_stall=1'b0. 2. Tied S_AXI_ARREADY to 0, so the AXI read handshake is not modeled; requests remain asserted while S_AXI_ARVALID is high. 3. Removed all other formal properties from axilxbar.v except the read-grant consistency checks under CHECK_MASTER_GRANTS. 4. Changed the internal read grant representation to combinational signals driven by a fixed-priority per-slave arbiter. 5. Abstracted away the write path and all data paths; all unused outputs are tied to 0. 6. Did not modify addrdecode.v, skidbuffer.v, faxil_slave.v, or faxil_master.v. 7. Did not reduce NM or NS. 8. The candidate does not model the original dynamic grant holding, lingering, outstanding transaction tracking, or error-slave sharing; these are lost behaviors. 9. The original SBY configuration is not fully represented; this is a focused pilot. 10. The arbitration policy is changed to lowest-master-index priority per slave instead of the original deconfliction and lingering logic.
