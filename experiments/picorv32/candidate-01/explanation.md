Main source changes: The picorv32 core is replaced by a minimal 2-state fetch/execute loop that implements only the RV32I ADD instruction. All other instructions, memory operations, branches, IRQ, PCPI, compressed ISA, and CSR logic are removed. The RVFI interface is simplified to expose only the signals needed for the ADD check. Information removed: all processor behaviors except ADD and a basic instruction fetch. Expected relation: The simplified core will pass the original ADD instruction check (rvfi_insn_check with insn_add) under the assumption that the retired instruction is ADD, because it computes the correct sum and updates the register file. It will fail checks for any other instruction and does not model the full PicoRV32. It is a partial model intended to exercise the ADD specification.
